# ЭтноVзгляд

Онлайн-выставка победителей и призеров открытого фотоконкурса «ЭтноVзгляд».

## Номинации

- «Мосты единства»
- «Портрет современности»
- «Живая традиция»

Сайт работает без сборщика и внешних JavaScript-зависимостей. Для локального просмотра достаточно открыть `index.html` в браузере.
